01 / how it works

Three steps. One of them is clicking.

No pasting HTML. No "the second blue button in the header card". The agent gets the exact element and where it lives in your code.

step 1

Run setup

Registers the MCP server with Claude Code and Codex, installs the hook that delivers your selection, and unpacks the extension.

$ npx pointer-bridge setup
step 2

Load the extension once

Setup opens the extensions page and copies the folder path for you. Turn on Developer mode, click Load unpacked, paste.

chrome://extensions
step 3

Click and ask

Pick an element, add an optional note. The toast turns green when your agent has it.

Alt+ Shift+ P

Something off? npx pointer-bridge doctor checks every link from browser to agent and prints the fix.

02 / what the agent gets

Not a screenshot. The element, and its source.

  "screenshot": "crop.png"
}

Precise context

Tag, selector, visible text, trimmed HTML, key computed styles, ancestors and an optional cropped screenshot. Shift-click to pick up to ten elements in order.

Honest source mapping

The component chain and file, with a stated confidence. A wrong path is worse than none, so Pointer never guesses.

exact component-only none

Your own words

Type an instruction in the toast and it travels with the selection. No MCP? "Copy as prompt" puts a formatted block on your clipboard.

Delivery you can see

Pointer tells you when the agent actually read the selection, and what to do if it hasn't. No guessing whether it worked.

05 / safe by default

Your page stays on your machine.

✓
Loopback only
The bridge listens on 127.0.0.1 with a token, plus Host and Origin checks.
✓
No form values
Inputs are never read and passwords are masked.
✓
Auto-pairing
Pins your extension on first connect, so a web page cannot impersonate it.
✓
Sensitive sites off
Banking, mail and sign-in pages are blocked by default.
✓
No telemetry, no accounts
No hosted service. Nothing leaves your machine except to your agent.
✓
Page content marked untrusted
Fenced before your model sees it. Keep your agent's permission prompts on.
06 / faq

Questions people ask.

Is it on the Chrome Web Store?+

Not yet. Setup unpacks the extension and opens the extensions page, so installing is one "Load unpacked". Works in Chrome, Edge and other Chromium browsers.

Does it work on production sites?+

Yes for hints: selector, classes and text. Component and file mapping needs a dev build, since production builds strip that data, and Pointer says which confidence level you got.

Does it edit my files or the page?+

No. Pointer only reads the element you click. Your agent makes any edits, through its own permission prompts.

What if my agent has no MCP support?+

Use "Copy as prompt". It puts the same context on your clipboard as a formatted block you can paste anywhere.

Is it free?+

Yes. MIT licensed and open source.
